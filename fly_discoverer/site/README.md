# site — 배포되는 화면

정적 HTML 세 개. 빌드 단계가 없고 번들러도 없다. 버셀은 이 폴더를 그대로 서빙한다.

| 파일 | 화면 |
|---|---|
| `index.html` | 랜딩 |
| `1-discovery.html` | STEP 1 · 시판 전 탐색 |
| `2-pv.html` | STEP 2 · 시판 후 감시 |

## 구조

두 화면은 원래 Claude 의 Design 아트보드(`.dc.html`)로 만들었고, 거기서
`<helmet>` 스타일 / `<x-dc>` 마크업 / 로직 스크립트를 뽑아 독립 HTML 로 합쳤다.
`dc-shim.js` 가 그 템플릿 문법을 브라우저에서 돌리는 최소 런타임이다:
`{{ 경로 }}` 치환, `sc-for`, `sc-if`, `onClick`, `setState` 후 전체 재렌더.

수치는 전부 하드코딩된 상수다. API 를 런타임에 부르지 않는다.
원본 응답은 저장소의 `measurements/` 에 있다.

## 고칠 때

- 색·간격 토큰은 각 파일 `<head>` 안 `:root` 에 있다. 두 파일이 같은 값을 쓴다.
- 수치를 바꿀 때는 `measurements/` 의 원본과 대조하고, 근거가 없으면
  `미조회` 또는 `—` 로 남긴다. 추정값을 채워 넣지 않는다.
- 각 화면 푸터의 크레딧 줄은 라이선스 요구사항이라 지우면 안 된다.
