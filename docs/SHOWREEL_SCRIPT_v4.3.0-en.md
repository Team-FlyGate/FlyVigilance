## Per-scene glossary

| STEP 1 · FlyDiscovery · pre-market candidates | NIM = NVIDIA AI models served by API · RMSD = distance between predicted and real binding pose (≤ 2 Å = reproduced) |
| STEP 1 · Drug panel · redocking | Redocking = checking that a model re-finds a known binding site · Å (ångström) = one ten-billionth of a meter |

| STEP 2 · FAERS warehouse | FAERS = FDA Adverse Event Reporting System · SDR = drug–event pair reported unusually often vs other drugs |

| STEP 2 · One real case | Triage = sorting cases by urgency · expedited report = serious, unexpected case reported to regulators within 15 days |
| Korean PV mode · Korean causality | MFDS = Korea's Ministry of Food and Drug Safety · WHO-UMC = WHO causality criteria · 15-day rule = serious-case deadline |
| SDR · PV classes · safety net | SDR = statistically unusual drug–event pair · PRR = proportional reporting ratio · DME = designated medical event (EMA) |
| Signal time machine · quarterly recompute | IC = information component: how much more than expected · FDA action = when the label added the reaction |
| Outcome-blinded measurement | McNemar test = compares two methods on the same cases · the smaller the p value, the less likely it is chance |
| Public reference-set validation | AUC = how well real signals are told from fakes (0.5 random · 1 perfect) · OMOP · EU-ADR · Harpaz = public answer sets |
| Official NVIDIA Agent Skills, applied | Agent Skills = task playbooks NVIDIA publishes for agents · reranker = re-sorts search results by relevance |
| Licensed pharmacist review, applied | Licensed pharmacist review = a practicing pharmacist checked agent output, and the fixes became rules |
| Connectome-routed architecture | Connectome = wiring map of the fruit-fly brain · routing = choosing which judgment path each case takes |
| NemoClaw · OpenShell · OpenClaw | NemoClaw · OpenShell = NVIDIA sandboxed runtime · OpenClaw = the agent that runs commands inside it |
| FlyGate Agent CLI | CLI = a tool you use by typing commands in a terminal · every output is JSON with evidence IDs |
| CLI · INSTALL · one-line install | Install script = creates a virtual environment and puts the flygate command on PATH |
| CLI · TRIAGE · case triage | triage = case classification · evidence_ids = IDs of the source records behind a conclusion |
| CLI · GRADE · label · signal · literature | grade = one grade from label, signal and literature · PRR = proportional reporting ratio |
| CLI · CRITIC · beyond evidence, rejected | safe / flagged = claims Nemotron Safety Guard passed / sent back |
| CLI · DOCK · DiffDock NIM, live | DiffDock = NVIDIA NIM model that predicts how a drug sits on a protein |
| CLI · KR · Korea's 15-day rule | WHO-UMC = WHO causality criteria · 15-day rule = reporting deadline for serious, unexpected events |
| CLI · WATCH · always on · 0 submitted | watch = recomputes signals each quarter and queues them for review · people submit to regulators |
| CLI · same commands for humans and agents | OpenShell sandbox = isolated environment where the agent runs the same commands |
