## 플랫폼별 추천

길이 제한은 계정 종류와 시기에 따라 바뀌므로, 올리기 전에 각 플랫폼의 현재 기준을 한 번 확인해 주세요.

| 플랫폼 | 추천 파일 | 이유 |
| --- | --- | --- |
| YouTube (일반 영상) | 쇼릴 16:9 (한국어 · 영어 각각) | 전체 내용을 원래 화면 그대로 보여 줍니다. 자막이 화면에 새겨져 있어 소리 없이도 읽힙니다 |
| YouTube Shorts | 티저 9:16 | 쇼츠는 짧은 세로 영상용입니다. 4분 쇼릴은 길어서 일반 영상으로 올립니다 |
| Instagram 릴스 · TikTok | 티저 9:16 · 필요하면 쇼릴 9:16 | 첫 노출은 티저가 좋고, 전체 설명이 필요하면 쇼릴 세로판을 씁니다(길이 제한 확인) |
| Instagram 피드 · Facebook | 티저 1:1 · 쇼릴 1:1 | 정사각이 피드에서 가장 크게 보입니다 |
| LinkedIn | 쇼릴 1:1 또는 16:9 (영어) | 긴 영상을 올릴 수 있고, 정사각이 모바일 피드에서 크게 보입니다 |
| X (Twitter) | 티저 16:9 또는 1:1 | 무료 계정은 올릴 수 있는 영상 길이가 짧아 4분 쇼릴이 들어가지 않을 수 있습니다 |
| 발표 · 심사 제출 · 홈페이지 | 쇼릴 16:9 HTML 링크 | 브라우저에서 바로 재생되고, 장면 목록으로 원하는 곳에 바로 갈 수 있습니다 |
| 카카오톡 · 메신저 공유 | `https://flygate.kr` 링크 | 공유 미리보기 이미지(OG)가 붙습니다 |

## 규격별 화면 구성

- **16:9**: 장면을 조금 줄여 위에 두고, 아래 띠에 자막(최대 두 줄)을 둡니다. 용어 풀이는 오른쪽 아래 고정 자리에 뜹니다.
- **1:1 · 9:16**: 16:9 장면을 가운데에 두고, 위에는 FlyGate와 장면 이름, 아래에는 큰 자막과 용어 풀이를 둡니다. 휴대전화에서도 자막을 읽을 수 있는 크기입니다.
- 다른 규격이나 언어가 필요하면 `scripts/render_reel.py OUT.mp4 30 <HTML 주소> wide|square|vertical` 로 다시 뽑을 수 있습니다.
