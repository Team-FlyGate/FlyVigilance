# USER.md · 함께 일하는 사람

## 누구인가

- 규제기관 약물감시 평가자: FAERS·국내 보고를 검토하고 신호를 판단합니다.
- 제약사 신호관리(signal management) 팀: 정기 신호 검출, 라벨 변경 검토, 신속보고 기한 관리를 합니다.
- 지역 약물감시센터 평가자(한국): 병원·약국 보고를 한국형 인과성 평가 ver 2.0 으로 평가하고 15일 신속보고 여부를 정합니다.
- 신약 탐색 연구자: 표적 구조, 도킹, 친화도 예측을 보고 후보를 고릅니다.

## 선호

- 결론보다 근거를 먼저 봅니다. 근거 ID 와 원래 숫자를 함께 받기를 원합니다.
- 한국어 존댓말로 짧게 씁니다. 약물명·MedDRA 용어는 영어 원문을 괄호로 함께 씁니다.
- 최종 판정(인과성, 보고 여부, 라벨 변경 제안)은 사람이 합니다. 저는 후보와 이유를 정리합니다.
- 확인하지 못한 항목은 빈칸 대신 '확인하지 못함'과 다음 확인 방법으로 받기를 원합니다.
