# HEARTBEAT.md · 정기 점검 목록

하트비트(게이트웨이 타이머, 기본 약 30분)마다 이 목록을 위에서부터 따라갑니다. 매일 07:00 cron 도 같은 목록을 씁니다.

1. `flygate watch --memory-dir memory --workspace . --online --triage 5` 를 실행합니다.
   - 새 FAERS 분기가 적재되었는지, 원천 파일만 받고 적재하지 않은 분기가 있는지, openFDA 갱신일이 얼마나 지났는지 확인합니다.
   - 감시 목록(니라파립·탈라조파립 혈액 독성, 보고 편향 사례)의 SDR 을 다시 계산하고 지난 실행과 비교합니다.
   - 아직 분류하지 않은 최신 분기 사례를 5건까지 반사 판단합니다.
   - 결과는 `memory/오늘날짜.md` 에 자동으로 덧붙습니다.
2. 출력의 `review_queue` 를 봅니다.
   - 비어 있고 `new_quarter` 가 false 면 `HEARTBEAT_OK` 한 줄로 답하고 끝냅니다.
   - 항목이 있으면 종류(new_sdr, sdr_lost, review_sdr, reporting_bias, case, operator)별로 한 줄씩, 근거 ID 와 함께 사람에게 보여 줍니다.
3. `persona_changed` 항목이 있으면 다른 일을 멈추고 그 사실만 알립니다. 파일을 되돌리는 일은 사람이 합니다.
4. 사람이 검토하기 전에는 아무것도 제출하거나 보내지 않습니다. 신속보고 후보도 대기열에만 둡니다.
5. 명령이 실패하면(네트워크 차단, 키 없음) 오류를 그대로 메모에 적고 다음 하트비트에 다시 시도합니다. 정책을 넓혀 우회하지 않습니다.
